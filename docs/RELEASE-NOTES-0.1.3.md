NetPanel 0.1.3：APP、通用 Root 配套模块与完整部署教程。

- APP：单屏概览、真实 DNS/Mihomo 状态与流量、当前节点、三栏主体侧滑。
- Root 模块：独立持久化目录、开机启动两个官方核心、原生 WebUI、随机认证、保留配置、按进程归属启停。仅支持 arm64。
- 配置：不含任何个人节点或订阅，默认 DIRECT，默认不启用 TUN、不改系统代理/私人 DNS/防火墙。
- 文档：完整安装、认证、APP 设置、节点自行导入、可选 TUN、升级、回退和故障排查。

下载 `NetPanel-0.1.3-debug.apk` 安装 APP；在已有 Root 管理器中安装 `NetPanel-Root-0.1.3-arm64.zip`。不要将 GitHub 自动生成的 Source code ZIP 当作模块刷入。默认服务有随机认证，需要按教程填写 API 凭据，MetaCubeXD 自己的连接配置也要填写。

APP：13 项单元测试、5 项真机测试通过。Root：官方核心真实配置校验、隔离启动/重启/停止、认证、WebUI、DNS 请求、配置保留与 PID 保护测试通过。尚未完成实际刷入重启、多 Root 管理器和 TUN 接管矩阵，因此本次整套配套发布标记为预发布。

附件包含：APP、Root 模块、通用配置、离线部署教程、验证记录、项目源码、第三方对应源码及 SHA-256 清单。所有附件均不包含个人节点、订阅、运行配置或发布凭据。详细步骤请先看随附 DEPLOYMENT.md。
